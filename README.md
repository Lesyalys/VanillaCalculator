# Калькулятор

**СурГУ · Предмет: Программирование на языке JavaScript**

Веб-приложение «Калькулятор» на чистом HTML, CSS и JavaScript.

Макет: [Figma](https://www.figma.com/design/UldYszi4j4XqmxnCE9COFh/%D0%9A%D0%B0%D0%BB%D1%8C%D0%BA%D1%83%D0%BB%D1%8F%D1%82%D0%BE%D1%80?node-id=2003-47)

## Функциональность

- **0–9, `,`** — ввод числа в поле дисплея.
- **AC** — All Clear: полная очистка поля ввода и состояния.
- **`+`, `−`, `×`, `÷`, `%`** — арифметические операции над числами.
- **`=`** — выполняет выбранную операцию над введёнными числами.
- **MS** — Memory Save: сохраняет число в память (перезаписывает).
- **MC** — Memory Clear: очищает память.
- **MR** — Memory Read: вставляет число из памяти в поле ввода.
- **M+** — прибавляет число к значению в памяти.
- **M−** — вычитает число из значения в памяти.

Память сохраняется в `localStorage` и не теряется при перезагрузке страницы.

## Технологии

- HTML5
- CSS3
- JavaScript

## Структура проекта
```

.
├── index.html # точка входа
├── style.css # стили (адаптив)
└── src/
├── Calculator.js # модель: состояние + логика
├── Renderer.js # отрисовка DOM
├── data.js # данные кнопок
└── operations.js # таблица операций

````

## Запуск

Открыть `index.html` в браузере.

Либо через локальный сервер (ES-модули требуют `http://`):

```bash
npx serve .
# или
python -m http.server
````

## Архитектура

- **data.js** — декларативное описание кнопок (id, value, type, classStyle).
- **Calculator.js** — хранит состояние (`display`, `previous`, `operator`, `memory`) и обрабатывает нажатия.
- **Renderer.js** — строит DOM из данных, обновляет дисплей. Не знает про математику.
- **operations.js** — таблица операций (`add`, `sub`, `mul`, `div`).
